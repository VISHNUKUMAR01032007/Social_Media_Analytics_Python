# Social Media Analytics Using Python

## 📌Overview

This project analyzes social media messages, including **Twitter and Facebook posts from U.S. politicians in 2013**. The data is processed and analyzed to identify **hashtags, sentiment, politician information, and social media trends**.

## 🎯Objectives

* Clean and organize social media data.
* Extract politician names, locations, and positions.
* Analyze message sentiment.
* Identify and analyze hashtags.
* Compare positive and negative sentiments among politicians.
* Find popular hashtags and their average sentiment.

## 🛠️Technologies Used

* **Python**
* **Pandas**
* Lists, Sets, Dictionaries, and Objects
* Functions, Conditionals, Loops, and Classes

## 📂Dataset

The dataset contains social media messages posted by **U.S. politicians in 2013** over a two-day period.

**Source:** Kaggle

## 🔄Project Workflow

1. Load and preprocess the dataset.
2. Extract useful information from the original data.
3. Add columns for politician details, sentiment, and hashtags.
4. Filter and analyze messages based on politicians.
5. Analyze hashtag popularity and sentiment.
6. Compare positive and negative sentiment across politicians.
7. Generate insights from the analysis.

## 🔍Key Insights

The project helps understand:

* Politicians' social media activity.
* Popular hashtags and topics.
* Sentiment associated with different topics.
* Differences in social media communication among politicians.
